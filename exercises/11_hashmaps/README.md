# Mapas de dispersão (`HashMap`)

Um *hash map* permite associar um valor a uma chave. Talvez você conheça essa estrutura como [`unordered_map` em C++](https://en.cppreference.com/w/cpp/container/unordered_map), [dicionário em Python](https://docs.python.org/3/tutorial/datastructures.html#dictionaries) ou *array associativo* em outras linguagens.

Essa é outra estrutura de dados importante, além dos vetores (`Vec`) que estudamos anteriormente.
