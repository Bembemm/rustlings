# Ponteiros inteligentes

Em Rust, ponteiros inteligentes são valores que armazenam um endereço de memória para outros dados, mas também fornecem metadados e comportamentos adicionais.

Muitos ponteiros inteligentes possuem os dados para os quais apontam, enquanto referências comuns apenas os emprestam.
