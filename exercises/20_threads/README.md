# Threads

Na maioria dos sistemas operacionais atuais, o código de um programa é executado dentro de um processo, e o sistema operacional administra vários processos ao mesmo tempo.

Dentro de um único programa, também podemos ter partes independentes executando simultaneamente. Essas unidades de execução são chamadas de *threads*.
