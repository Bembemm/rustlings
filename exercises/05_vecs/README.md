# Vetores (`Vec`)

Os vetores são uma das estruturas de dados mais utilizadas em Rust. Em algumas outras linguagens, uma estrutura semelhante costuma ser chamada de array. Em Rust, porém, há uma diferença importante: arrays possuem tamanho fixo, conhecido durante a compilação, e normalmente armazenam seus elementos diretamente no local onde o array é criado. Já os vetores utilizam alocação na *heap* e podem aumentar ou diminuir de tamanho.

Os vetores aparecem mais adiante no livro, mas são tão úteis que vamos apresentá-los agora. Outra estrutura de dados importante, o *hash map*, será estudada depois.
