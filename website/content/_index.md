## Início rápido

```bash
# Instalação
cargo install rustlings
# Inicialização
rustlings init
# Entrar no novo diretório
cd rustlings
# Iniciar o Rustlings
rustlings
```

Visite a página de [**configuração**](@/setup/index.md) para mais detalhes 🧰
